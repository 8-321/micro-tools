Why these nine

They are the nine shapes that keep coming back in this batch: a message-first assistant, a paperwork pack, a group planner, a profile, an application kit, a backtest, a portfolio view, a trade brief and an alert. Each company solved it with data, model access or a broker connection. Take away the data and the broker, and what is left is still a useful tool — that is what these are: the part a normal person can run offline, today.

Every page is one HTML file plus two shared assets. No build step. Host it anywhere static, or hand it to a client as the starting point for the real thing.

Real screenshots, sample data loaded. Nothing is mocked up.

What you get

One download, nine folders. Each folder has a SKILL.md (the workflow, inputs, outputs and failure modes) plus a standalone index.html you can double-click. Shared assets/base.css and assets/base.js are plain readable source.

Works offline. No account, no API key, no upload, no telemetry. Open the file, paste your data, copy or download the result.

Who it fits

Good fit: freelancers and operators who do the same five-minute jobs every week; anyone who wants the parsing and the math without another subscription; developers who want a readable starting point they can fork.

Not a fit: if you need live market data, broker execution, OCR of scanned documents, or a hosted multi-user product. Those need the data pipes these tools deliberately leave out.

FAQ

Does it call any AI model? No. Every output is rule-based parsing and arithmetic, so it runs offline and gives the same answer twice.

Do I need Excel or Python? No. A browser tab is enough. CSV paste works for the finance tools.
